# ⏱️ 교실 TV용 수업 활동 타이머 (Classroom TV Timer)

수업 활동 시간에 교실 대형 TV 또는 전자칠판에 띄워두고 사용하는 고시인성 웹 타이머입니다.  
교실 맨 뒤(8~10m)에서도 한눈에 시간을 확인할 수 있도록 설계되었습니다.

---

## ✨ 주요 기능

- 🔍 **초대형 고시인성 디스플레이**: 화면 비율에 따라 반응형으로 최대화되는 글꼴 크기(`min(28vw, 46vh)`), 폰트 폭 떨림 없는 고정폭 정렬(`tabular-nums`).
- ⚡ **원터치 프리셋 버튼**: 5분, 10분, 15분 즉시 설정 및 `+1분` 빠른 연장.
- ✍️ **사용자 직접 시간 입력**: 원하는 분/초를 직접 입력하여 타이머 세팅.
- ⚠️ **1분 전 주의 환기 알림**: 남은 시간 1분 이하 진입 시 네온 앰버 색상 변경 + 호흡(Pulse) 애니메이션 + 주의 환기 차임(딩-동) 1회 재생.
- 🚨 **종료 시 화면 깜빡임 & 학교 종소리**: 0초 도달 시 화면 전체 플래시 효과 + "🔔 활동 시간이 종료되었습니다!" 대형 배너 + 4화음 학교 종소리(Westminster Chime) 자동 연주.
- 🎯 **스마트 집중 모드 (Auto-hide)**: 타이머 진행 중 마우스 움직임이 3초간 없으면 버튼들이 부드럽게 페이드아웃되어 타이머 숫자만 전체 화면에 가득 찹니다. (마우스 조작 시 즉시 복원)
- 📝 **활동명 즉석 수정**: 상단 "수업 활동 시간"을 클릭하여 "모둠 토의 시간", "수학 탐구 활동" 등으로 변경 가능 (`localStorage` 자동 저장).
- 🔇 **음소거 및 전체화면 지원**: 🔔/🔕 음소거 토글, ⛶ 원클릭 전체화면 토글.
- 🌐 **Zero Dependency (100% 오프라인 동작)**: 외부 패키지 설치나 인터넷 연결 없이 `index.html` 단독으로 동작.

## ⌨️ 키보드 단축키

| 단축키 | 동작 |
|---|---|
| <kbd>Space</kbd> | 시작 / 일시정지 |
| <kbd>R</kbd> | 타이머 초기화 (리셋) |
| <kbd>F</kbd> | 전체화면 토글 |
| <kbd>Esc</kbd> | 전체화면 종료 |

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Modern JavaScript (ES Modules)
- **Audio**: Web Audio API (외부 음원 파일 다운로드 없는 순수 브라우저 합성 사운드)
- **Testing**: Node.js 내장 테스트 러너 (`node --test`), Playwright MCP
