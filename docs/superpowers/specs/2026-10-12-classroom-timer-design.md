# Classroom TV Timer 웹앱 설계 사양서 (Design Spec)

- **작성일자**: 2026-10-12
- **프로젝트명**: 교실 TV용 고시인성 수업 활동 타이머 (Classroom TV Activity Timer)
- **대상 사용자**: 초/중/고등학교 교사 및 수업 참여 학생 전체
- **핵심 목표**: 교실 맨 뒤(8~10m)에서도 한눈에 보이는 초대형 디스플레이, 1분 전 직관적 경고, 종료 시 깜빡임 및 차임벨 알림, 오프라인 독립 구동.

---

## 1. 아키텍처 및 기술 스택

### 1.1 기술 스택
- **언어 및 표준**: HTML5, CSS3, Modern JavaScript (ES6+)
- **외부 의존성**: 0개 (Zero Dependency)
  - CDN, 외부 패키지, 빌드 도구 의존성 없음
  - 학교 교실 PC(Chrome, Edge, Whale) 및 스마트 TV 웹 브라우저에서 `index.html` 더블 클릭 또는 웹 서버 호스팅을 통해 즉시 구동
- **오디오 합성**: 브라우저 내장 **Web Audio API**
  - 외부 음원 파일(MP3, WAV) 없이 순수 수학적 주파수 오실레이터(OscillatorNode)와 게인 노드(GainNode)로 맑은 차임벨 합성
  - 인터넷 차단 및 오프라인 교실 환경에서도 100% 신뢰성 보장

### 1.2 파일 구조
```
d:\Codex\class-timer\
├── index.html       # 메인 마크업 (시맨틱 구조, 접근성 태그)

├── app.js           # 타이머 로직, 오디오 합성기, 단축키 및 전체화면 이벤트
└── docs/
    └── superpowers/

            └── 2026-10-12-classroom-timer-design.md
```

## 2. 화면 구성 및 UI 레이아웃

### 2.1 상단 유틸리티 바 (Header)
- **활동명 타이틀 (Editable Activity Title)**:
  - 기본값: `"수업 활동 시간"`
  - 교사가 텍스트를 클릭하여 `"모둠 토의 시간"`, `"개별 문제 풀이"` 등으로 인라인 수정 가능
- **오디오 음소거 버튼 (Mute Toggle)**:
  - 🔔 소리 켜짐 / 🔕 음소거 상태 토글
  - 기본값: 소리 켜짐 (Unmuted)
- **전체화면 버튼 (Fullscreen Toggle)**:
  - ⛶ 아이콘 클릭 시 브라우저 전체화면 API(`requestFullscreen`) 실행

### 2.2 메인 타이머 디스플레이 (Timer Display)
- **숫자 형식**: `MM:SS` (1시간 이상 입력 시 `HH:MM:SS` 유연 대응)
- **타이포그래피**:
  - `font-size: min(28vw, 46vh)` - 화면 가로/세로 비율에 맞춰 최대화
  - `font-family`: `system-ui, -apple-system, 'Pretendard', 'Noto Sans KR', sans-serif`
  - `font-variant-numeric: tabular-nums` (숫자가 변경되어도 가로 폭이 떨리지 않는 고정폭 정렬)
  - `font-weight: 800` (극대화된 굵기와 선명도)
- **배경 및 색상**:
  - 교실 TV의 눈부심 방지와 높은 명도 대비를 위한 다크 슬레이트(#0f172a / #1e293b) 배경
  - 일반 상태 글자 색상: 선명한 네온 에메랄드 그린 / 화이트 (#10b981 / #f8fafc)

### 2.3 하단 컨트롤 패널 (Controls)
- **프리셋 빠른 버튼**: `[ 5분 ]`, `[ 10분 ]`, `[ 15분 ]` 버튼 (원터치 즉시 시간 설정)
- **직접 입력 필드 (Custom Input)**:
  - `[ 분 ] 분 [ 초 ] 초` 입력 필드 + `[설정]` 버튼
  - 유효성 검사 (0초 이하, 음수, NaN 방지)
- **동작 제어 버튼 (Action Buttons)**:
  - `[ 시작 / 일시정지 ]` (크고 강조된 주요 액션 버튼)
  - `[ 재설정 (리셋) ]` (원래 설정했던 시간으로 초기화)
  - `[ +1분 추가 ]` (활동 연장 필요 시 즉시 1분 추가)
- **스마트 집중 모드 (Auto-Hide Controls)**:
  - 타이머가 실행 중(`running`)일 때, 마우스 움직임이 3초간 없으면 컨트롤 바가 `opacity: 0`으로 부드럽게 페이드아웃
  - 마우스를 움직이거나 화면을 터치/클릭하면 즉시 `opacity: 1`로 복원

## 3. 상태 관리 및 피드백 (State & Feedback)

| 상태 (State) | 조건 | 시각적 표현 | 오디오 효과음 |
|---|---|---|---|
| **정지 / 대기 (Idle)** | 시작 전 또는 리셋 상태 | 컨트롤 전체 표시, 안정적인 민트/화이트 숫자 | 없음 |
| **일반 진행 (Running Normal)** | 남은 시간 > 60초 | 편안하고 뚜렷한 에메랄드/화이트 폰트, 프로그레스 바 표시 | 없음 |
| **1분 전 경고 (Warning)** | 0초 < 남은 시간 ≤ 60초 | 글자색이 **네온 앰버/오렌지(#f59e0b)**로 전환, 부드러운 1초 간격 펄스 효과 | 1분 진입 시 2음 주의 환기 차임 (C5 -> G5) 1회 재생 |
| **시간 종료 (Finished)** | 남은 시간 == 0초 | 화면 전체가 **레드/골드로 교차 깜빡임(Flash Animation)**, **"🔔 활동 시간이 종료되었습니다!"** 대형 배너 표시 | 청명한 학교 종소리 4화음 차임 (E5 - C5 - D5 - G4 등) 재생 |

## 4. Web Audio API 사운드 명세

- **주의 환기 차임 (1분 전)**:
  - 사인파(Sine wave) 2음 연속: 523.25Hz (C5, 0.25초) -> 783.99Hz (G5, 0.4초), 부드러운 지수 감쇠(exponentialRampToValueAtTime)
- **종료 종소리 (0초)**:
  - 친숙한 학교 차임벨 멜로디 (예: 미-도-레-솔): 659.25Hz(E5) -> 523.25Hz(C5) -> 587.33Hz(D5) -> 392.00Hz(G4)
  - 자연스러운 종소리 울림(Decay envelope) 적용
- **브라우저 자동재생 정책 대응**:
  - 첫 사용자 클릭(시작 버튼, 프리셋 클릭 등) 시 `audioCtx.resume()` 활성화

## 5. 키보드 단축키 & 접근성

- `Space`: 시작 / 일시정지 토글
- `R` / `r`: 타이머 리셋
- `F` / `f` (또는 `F11`): 전체화면 토글
- `Esc`: 전체화면 해제
- 모바일/태블릿 터치 디스플레이 완벽 지원

## 6. 품질 및 테스트 기준

1. **시인성 검증**: 1920x1080 (FHD) 및 3840x2160 (4K) 해상도에서 폰트 깨짐 없이 화면 중앙에 안정적으로 렌더링되는가?
2. **타이머 정밀도**: `setInterval` 드리프트를 방지하기 위해 실제 타임스탬프(`performance.now()` 또는 `Date.now()`) 기반으로 시간 계산이 정확한가?
3. **상태 전환 무결성**: 60초 진입 시 색상 전환 및 소리 발생, 0초 진입 시 화면 플래시 및 종료 안내 배너 표시가 즉각적인가?
4. **오프라인 동작**: 외부 네트워크 연결이 끊긴 상태에서도 모든 기능이 정상 동작하는가?
